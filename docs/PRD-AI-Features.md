# PRD — AI 功能路线图

> 最后更新：2026-05-20
> 项目：nuke-ai-collaborator

---

## 一、AI 能力增强（纵向）

| 功能 | 状态 | 说明 |
|---|---|---|
| 流式输出（打字机效果） | ✅ 已完成 | SSE + WebSocket 逐 token 推送 |
| 多模型支持（OpenAI / Ollama / Claude） | ⬜ 未做 | 后端 ai_client.py 已有基础结构，前端 Bot 创建时可选模型，但缺少完整测试和 UI 验证 |
| Bot 工具调用（Tool Call / Function Calling） | ⬜ 未做 | Bot 可调用结构化外部 API，支持 OpenAI function_call 格式 |
| 自定义工作流（可视化角色链） | ⬜ 未做 | 可视化配置多个 Bot 的协作顺序和触发条件 |
| 更智能的记忆（跨群组知识库） | ⬜ 未做 | 当前 Chroma RAG 仅限单群组；需支持跨群组共享知识 |
| Bot 人格配置（温度、风格等） | ⬜ 未做 | 暴露 temperature、top_p、max_tokens 等参数给用户配置 |

---

## 二、Bot Workspace & Skill 执行（纵向）

| 功能 | 状态 | 说明 |
|---|---|---|
| Bot 独立工作区 | ⬜ 未做 | 每个 Bot 有独立文件目录、状态、执行历史 |
| 内置 Skill 库 | ⬜ 未做 | 预置常用技能：网络搜索、代码执行、读写文件等 |
| 自定义脚本注册 | ⬜ 未做 | 用户可上传 Python 脚本注册为 Bot 可调用工具 |
| 代码执行沙箱 | ⬜ 未做 | Bot 生成的代码可在隔离环境中直接运行，结果回显到聊天 |
| 定时任务 | ⬜ 未做 | Bot 可配置 cron 定时发消息 / 执行任务 |
| Bot 工作流编排 | ⬜ 未做 | 可视化拖拽配置多 Bot 协作流程（类 n8n） |

---

## 三、现有 AI 功能缺口（需补齐）

| 功能 | 状态 | 说明 |
|---|---|---|
| 角色模板 → 一键添加到群组 | ⬜ 未做 | TemplateManager 仅管理模板，缺少「添加到当前群组」按钮 |
| 内置模板库预置内容 | ⬜ 未做 | 数据库无预置模板，首次使用为空；需预置 ~10 个常用角色 |
| Bot 编辑（改提示词 / 模型） | ⬜ 未做 | 创建后无编辑入口，只能删除重建 |
| 图片理解 | ⬜ 未做 | 用户上传图片后 AI 看不到内容；需将图片 URL 传给支持视觉的模型（GPT-4o / Claude claude-sonnet-4-6） |
| 清除 Bot 对话历史 | ❌ 放弃 | 群组记忆应持续沉淀，遗忘反而有害；Bot 已有摘要压缩机制应对长上下文 |
| @all 多 Bot 协作顺序控制 | ⬜ 未做 | 当前 @all 触发所有 Bot 同时乱序回复，缺顺序 / 轮流模式 |

---

## 优先级建议

**P0（核心体验，尽快补齐）**
1. Bot 编辑
2. 角色模板一键添加到群组
3. 内置模板预置内容
4. 清除 Bot 对话历史
5. Bot 人格配置（temperature 等）

**P1（差异化能力）**
6. 图片理解
7. Bot 工具调用 / Function Calling
8. 代码执行沙箱
9. 定时任务

**P2（高级功能）**
10. 跨群组知识库
11. Bot 独立工作区
12. 自定义工作流 / 可视化角色链
13. Bot 工作流编排（n8n 风格）
14. 内置 Skill 库 + 自定义脚本注册
