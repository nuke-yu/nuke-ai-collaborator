Part 2 · 产品能力　/　S10

离开复盘 Recap

AI 团队 7×24 干活，你回来一张卡片秒懂——不掉线。
  • 离开复盘（Away Recap）：你离开期间群里发生了什么，回来一卡片秒懂；一键 dismiss，刷新不丢。
  • 自动复盘报告（Retro）：每轮交付结束自动生成 run 报告——设计决策、技术债自动归档进 retros/。
  • 事件驱动：工作流暂停 / 完成自动触发，不用人手点。
价值：进展 / 决策 / 技术债不靠人脑记；交接、审计、复盘有据可查——直接打「知识蒸发」痛点。

Part 2 · 产品能力　/　S11

智能建议 Smart-Compose

下一步说啥，它替你想。
  • 基于最近对话 + 执行历史，实时生成 2–3 条「下一步可发给 Bot」的自然语言草稿。
  • 每条都 @ 真实 Bot、具体可执行、带安全护栏（绝不生成 /confirm、/abort 等系统命令）。
  • 带缓存，即时返回，不卡顿。
S8 的人确认门给你控制权，Recap + Smart-Compose 让这份控制权毫不费力（理解过去 + 驱动未来）。

S15 · 16 / 29
1
护城河①

蜂窝物理隔离

一个群一个项目（Project-Cell），从数据到进程，物理隔离。
  • 每群独立 SQLite 库 + 独立向量记忆 + 独立 Bot 与权限；物理文件隔离 = 天然无锁，杜绝跨项目库锁死与数据泄漏。
  • 进程级隔离：一个项目崩溃，不波及其他项目（高可用）。
  • 内存性价比：LRU 驱逐——超 30 分钟 不活跃自动持久化释放，新消息 秒级 Rehydrate 唤醒，超低 TCO。
商业价值：满足企业数据合规与项目保密 + 极低托管成本，可放心给多客户 / 多团队同时用。
S16 · 17 / 29
2
护城河②

可信与治理

纵深安全，让 AI 进得了生产环境。
  • 人确认门：写操作、关键推进需人工审批。
  • 双层命令防护 + 密钥自动脱敏 + 子 Agent 权限衰减。
  • 确定性控制平面（Schema-First）：推进由结构化工具调用驱动（signal_stage_done / signal_rework）而非正则，可审计、不随温度漂移；保留哨兵 fallback 兜底。
商业价值：把「不敢放权」变成「放权也安心」——这是 to B 落地的入场券。
S17 · 18 / 29
3
护城河③

知识资产化 · 记忆复利

Bot 不是用完即弃，是会成长、且记得「干净可信」的数字员工。
  • 生成式记忆架构：对话 → 事实抽取 → 反思固化（episodic→semantic），不是存聊天记录。
  • 三因子加权混合检索（重要性 + 时近性 + 相关性）+ 关键词增强，取回最该用的那条。
  • 时间衰减 + TTL + 冲突消解：过时、矛盾的自动退场，记忆不腐烂。
  • A-MEM 来源链 + 群隔离 + 写入脱敏：每条可追溯出处、按群隔离、入库前脱敏。
商业价值：用得越久 Bot 越懂项目，迁移成本越高——复利型护城河，不是一次性功能。

Part 3 · 技术深潜　/　S19

记忆系统：工业级认知记忆架构

① 写入提取 对话 → 抽取原子事实(salience 0~1) → 冲突消解 → 写入(脱敏) ② 周期反思 水位线增量取新事实 → 闸门 → LLM 提炼洞察 → 写回(A-MEM 溯源链) ③ 检索装配 Query 重写 → 向量召回(bot+group 硬隔离) → 三因子精排 → 注入
  • 三因子加权：0.5·相似 + 0.3·时近(7天半衰期) + 0.2·重要性 + 关键词 + 反思特权。
  • 防污染：冲突消解只删检索候选集内 ID（防 LLM 捏造 ID 误删）；写入前脱敏。
  • 对标学术 SOTA 的工程化落地：Generative Agents · A-MEM · Reflexion · MemGPT。
别人的「记忆」是把聊天记录塞回 prompt；我们的记忆会打分、消解冲突、反思固化、随时间遗忘、可追溯来源——这是工业级认知记忆，不是 RAG。
