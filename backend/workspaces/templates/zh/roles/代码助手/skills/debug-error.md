# Debug Error

## 排查框架

```
现象 → 假设 → 验证 → 根因 → 修复 → 回归
```

## 步骤

1. **复现错误** — 确认完整 stack trace，确认复现步骤
2. **缩小范围** — 最近改动了什么？错误在哪一层？
3. **列出假设** — 从最可能到最不可能排列
4. **逐一验证** — 添加日志 / 断点，隔离最小复现用例
5. **确认根因** — 「因为 X，导致 Y，表现为 Z」
6. **实施修复** — 最小改动原则，说明为什么这样改
7. **回归验证** — 运行测试，确认修复且无新 bug

## 输出格式

```
### 根因
因为 [原因]，导致 [现象]。

### 修复方案
[代码或操作步骤]

### 验证方法
运行 [...] 确认修复。
```
