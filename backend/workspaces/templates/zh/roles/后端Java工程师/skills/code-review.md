# Code Review（Java）

## 评审维度

1. **设计** — 是否符合 SOLID 原则，有无过度设计或职责混乱
2. **并发安全** — 共享状态是否线程安全，有无竞态条件
3. **异常处理** — 是否捕获了正确的异常层级，有无吞掉异常
4. **性能** — 有无 N+1 查询、不必要的对象创建、阻塞调用
5. **可读性** — 命名是否清晰，方法是否过长
6. **测试性** — 依赖是否可注入，是否便于单测

## 步骤

1. 通读代码，理解意图
2. 按维度逐一检查
3. 区分 **必须修改**（Bug/安全/并发）和 **建议优化**（风格/性能）
4. 给出修改示例（代码片段）
