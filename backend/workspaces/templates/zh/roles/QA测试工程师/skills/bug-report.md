# Bug Report

## 缺陷报告要素

- **标题** — 一句话描述：[在什么情况下][做了什么操作][出现了什么结果]
- **严重程度** — Blocker（阻塞）/ Critical（严重）/ Major（主要）/ Minor（次要）
- **优先级** — P0（立即修复）/ P1（当前版本）/ P2（下版本）
- **复现步骤** — 精确到每一步操作
- **实际结果** — 观察到的现象
- **预期结果** — 正确行为应该是什么
- **环境信息** — 操作系统、浏览器/App 版本、测试环境
- **附件** — 截图、日志、录屏

## 步骤

1. 收集 bug 描述信息
2. 补充缺失的环境和复现信息（如未提供则标注"待补充"）
3. 按模板整理输出

## 输出格式

```
### 缺陷报告

**标题：** [标题]
**严重程度：** [级别]  **优先级：** [级别]

**复现步骤：**
1. ...
2. ...

**实际结果：** ...
**预期结果：** ...

**环境：** OS: xxx | 浏览器: xxx | 版本: xxx

**附件：** [截图/日志描述]
```
