# Polish Translation

## 润色维度

1. **通顺性** — 句子是否符合目标语言习惯，有无翻译腔
2. **一致性** — 同一术语在全文中译法是否统一
3. **准确性** — 是否有漏译、误译、过度意译
4. **风格匹配** — 语气是否与原文一致（正式 / 口语 / 学术）

## 步骤

1. 对比原文与译文，逐段检查
2. 标出问题（通顺性 / 准确性 / 风格）
3. 给出修订版本
4. 说明主要改动原因

## 输出格式

```
### 修订后译文
[完整修订版本]

### 主要改动
- [原文] → [修订] — 原因：...
```
