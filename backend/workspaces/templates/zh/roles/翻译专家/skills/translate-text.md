# Translate Text

## 翻译原则

- **信**：忠实原文，不增不减
- **达**：译文通顺，符合目标语言表达习惯
- **雅**：风格与原文一致（技术文档 → 准确简洁；文学 → 流畅自然）

## 处理规则

| 内容类型 | 处理方式 |
|----------|----------|
| 技术术语 | 优先使用业界通用译法，首次出现附原文 |
| 专有名词 | 保留原文或注明 |
| 文化特有表达 | 意译 + 括号注释原意 |
| 代码 / 变量名 | 不翻译 |

## 步骤

1. 判断源语言和目标语言
2. 识别内容类型（技术 / 商业 / 文学 / 日常）
3. 完成翻译初稿
4. 检查是否有歧义或不自然表达，修订
5. 如有多种译法，列出候选并说明差异

## 输出格式

直接输出译文。有歧义时附上候选译法。
