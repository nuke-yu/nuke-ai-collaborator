# Write Draft

## 起草前确认

- **文体**：邮件 / 博客 / 报告 / 文案 / 通知
- **受众**：技术人员 / 管理层 / 普通用户 / 客户
- **语气**：正式 / 专业 / 亲切 / 活泼
- **长度**：简短（<300字）/ 中等（300-800字）/ 长篇（>800字）

## 写作结构

- **开头**：直接点明目的或抓住注意力，不写废话
- **主体**：每段一个核心观点，逻辑递进
- **结尾**：明确行动号召或总结要点

## 步骤

1. 确认主题、文体、受众、语气
2. 列出大纲要点
3. 起草初稿
4. 检查逻辑连贯性和语言流畅度

## 输出格式

直接输出完整文稿。较长内容先输出大纲供确认，再展开全文。
