# Tech Stack Review

## 评估维度

| 维度 | 说明 |
|------|------|
| 成熟度 | 社区活跃度、生产案例、LTS 支持 |
| 团队匹配 | 现有技能储备、学习曲线 |
| 性能 | 延迟、吞吐量、资源消耗 |
| 运维成本 | 部署复杂度、监控、故障处理 |
| 生态 | 与现有技术栈的集成难度 |
| 锁定风险 | 是否绑定单一厂商 |

## 步骤

1. 明确选型场景和核心诉求（性能优先？稳定性？开发效率？）
2. 列出候选方案
3. 按维度逐一评分（1-5分）
4. 给出推荐方案和理由
5. 说明不选其他方案的原因

## 输出格式

```
## 技术选型分析：[场景]

### 候选方案对比
| 维度 | 方案A | 方案B | 方案C |
|------|-------|-------|-------|
| ...  |  ...  |  ...  |  ...  |

### 推荐：方案X
原因：...

### 不选其他方案的原因
- 方案B：...
```
