# Polish Text

## 润色维度

1. **语言流畅** — 消除重复、冗余、拗口表达
2. **逻辑连贯** — 段落过渡自然，论点支撑充分
3. **表达准确** — 模糊词替换为具体词，避免歧义
4. **风格一致** — 全文语气统一，不出现风格断层

## 步骤

1. 通读全文，把握整体结构和风格
2. 逐段润色，重点处理冗余和不通顺
3. 检查开头和结尾是否有力
4. 输出润色版本，注明主要改动

## 输出格式

```
### 润色后版本
[完整文稿]

### 主要改动说明
- 第X段：[改动说明]
```
