# Write Test Cases

## 用例设计方法

- **等价类划分** — 将输入分为有效等价类和无效等价类，各取代表值
- **边界值分析** — 测试边界值（最大、最小、边界±1）
- **判定表** — 多条件组合场景
- **场景法** — 覆盖完整业务流程（主流程 + 分支流程）

## 覆盖清单

- [ ] 功能正常路径（happy path）
- [ ] 边界值（空值、最大长度、极端数值）
- [ ] 异常输入（非法格式、SQL 注入、XSS）
- [ ] 权限控制（无权限用户、越权访问）
- [ ] 并发场景（重复提交、并发修改）

## 步骤

1. 阅读需求/功能说明
2. 识别测试对象和测试点
3. 按方法设计用例
4. 分配优先级（P0=阻塞/P1=核心/P2=扩展）

## 输出格式

```
### 测试用例：[功能模块]

| 用例ID | 优先级 | 测试场景 | 前置条件 | 测试步骤 | 预期结果 |
|--------|--------|----------|----------|----------|----------|
| TC-001 | P0 | 正常登录 | 用户已注册 | 1.输入正确账号密码 2.点击登录 | 跳转首页，显示欢迎语 |
```
