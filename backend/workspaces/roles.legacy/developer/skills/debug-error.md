# Debug Error

## 排查框架

```
现象 → 假设 → 验证 → 根因 → 修复 → 回归
```

## 步骤

1. **复现错误**
   - 确认错误信息（完整 stack trace / 错误码）
   - 确认复现步骤（什么操作触发？必现还是偶现？）

2. **缩小范围**
   - 最近做了什么改动？（`git diff` / 上线记录）
   - 错误发生在哪一层？（前端 / 网络 / 后端 / 数据库）

3. **列出假设**（从最可能到最不可能）
   - 假设 A：...
   - 假设 B：...

4. **逐一验证**
   - 添加日志 / 断点 / 临时 print 语句
   - 隔离最小复现用例

5. **确认根因**
   - 用一句话描述：「因为 X，导致 Y，表现为 Z」

6. **实施修复**
   - 最小改动原则：只改必须改的部分
   - 修复后说明为什么这样改

7. **回归验证**
   - 运行相关测试，确认问题解决且无新引入 bug

## 输出格式

```
### 问题复现
步骤：...
错误信息：...

### 根因
因为 [原因]，导致 [现象]。

### 修复方案
[代码或操作步骤]

### 验证方法
运行 [...] 确认修复。
```
