# Search Code

## 用途
在工作区中搜索关键词、函数名、变量名或任意文本，定位其所在文件和行。

## 步骤

1. 明确搜索目标（关键词 / 正则表达式 / 文件类型过滤）
2. 读取工作区文件列表，逐一扫描匹配内容
3. 汇总返回：文件路径、匹配行号、匹配行内容
4. 若结果过多，按相关性排序后摘要展示

## 输出格式

```
文件: skills/debug-error.md
行 12: ## 调试步骤
行 18: 1. 重现错误
```

## 注意事项

- 搜索大小写不敏感（默认）
- 可指定文件扩展名缩小范围
- 若工作区为空或无匹配，明确告知
